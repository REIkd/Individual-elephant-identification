# 服务器部署清单（scp 上传代码）

> **方式：网络 scp 上传**（不用 U 盘）  
> 目标：`root@120.196.88.140:12222` → `/root/elephant_cloud/`  
> 端口：**9998**

---

## 一、Windows 一键上传

```powershell
cd "D:\Project\Individual elephant identification"
.\deploy_pack\upload_to_server.ps1
```

自定义地址：

```powershell
.\deploy_pack\upload_to_server.ps1 -Server "root@120.196.88.140" -Port 12222 -RemoteDir "/root/elephant_cloud"
```

---

## 二、手动 scp（等价命令）

```powershell
cd "D:\Project\Individual elephant identification"

scp -P 12222 cloud_server.py cloud_inference.py cloud_render.py elephant_clip_recorder.py `
  video_tracker_yolo.py predict.py classifier.py elephant_net.py paths.py `
  cloud_clip_env.sh start_cloud_server_linux.sh `
  allowed_elephants.json class_names.json `
  root@120.196.88.140:/root/elephant_cloud/
```

红外相机（若已部署）再加：

```powershell
scp -P 12222 uovision_camera.py uovision_registry.py uovision_open_api.py `
  uovision_video_pipeline.py uovision_cameras.json uovision_config.example.sh `
  setup_uovision_ir.sh root@120.196.88.140:/root/elephant_cloud/
```

> 模型 `best_elephant_model.pth`、`yolov8m.pt` 通常已在服务器，无需每次上传。

---

## 三、SSH 登录并重启

```bash
ssh -p 12222 root@120.196.88.140
cd ~/elephant_cloud
bash start_cloud_server_linux.sh
```

启动日志应含：

```text
网页直播: 关 → 使用 /watch/clips
录像库: .../data/clips | 保留 3 天
POST /api/v1/clips/upload     Pi 上传标注 MP4
```

---

## 四、本次更新文件说明

| 文件 | 作用 |
|------|------|
| `cloud_server.py` | Pi 上传接口、关直播、3 天清理 |
| `cloud_inference.py` | 不再生成 MJPEG |
| `elephant_clip_recorder.py` | 存 Pi 上传的 MP4 |
| `cloud_clip_env.sh` | `LIVE_STREAM_ENABLE=0` 等 |
| `start_cloud_server_linux.sh` | 加载 cloud_clip_env |

## 六、环境变量（cloud_clip_env.sh）

| 变量 | 默认 |
|------|------|
| `LIVE_STREAM_ENABLE` | `0` 关闭直播 |
| `ELEPHANT_CLIP_RETENTION_DAYS` | `3` 天 |
| `ELEPHANT_CLIP_RECORD_INFER` | `0` 不由服务器录 Pi 流 |
