# 树莓派部署清单（U 盘 / 移动硬盘拷贝）

> **方式：物理拷贝**（Windows 拷到 U 盘 → 插 Pi 安装）  
> **不用** scp/网络传 Pi 代码  
> 目标目录：`~/pi_cloud_deploy`

---

## 一、Windows：打包到 U 盘

```powershell
cd "D:\Project\Individual elephant identification"
.\deploy_pack\copy_to_usb_for_pi.ps1 -UsbRoot "E:\elephant_pi"
```

将 `E:\elephant_pi\` 整个文件夹复制到 U 盘（或移动硬盘）。

---

## 二、Pi：从 U 盘安装

1. U 盘插入树莓派  
2. 找到挂载路径，例如 `/media/pi/USB/elephant_pi`

```bash
# 查看 U 盘路径
ls /media/pi/
# 或
ls /mnt/

# 安装
bash /media/pi/USB/elephant_pi/install_on_pi.sh /media/pi/USB/elephant_pi
```

3. 编辑配置（改服务器地址）：

```bash
nano ~/pi_cloud_deploy/pi_cloud_config.sh
```

必改：

```bash
export ELEPHANT_SERVER="http://120.196.88.140:9998"
export CLOUD_API_KEY="elephant-demo-2026"
```

4. 运行：

```bash
cd ~/pi_cloud_deploy
./run_pi_cloud_client.sh
```

## 三、U 盘内文件列表

| 文件 | 说明 |
|------|------|
| `pi_cloud_client.py` | 主程序 |
| `pi_clip_recorder.py` | 1920 录像 + 上传 |

| `install_on_pi.sh` | **U 盘安装脚本** |
| `requirements-pi-client.txt` | 依赖 |
| `install_service.sh` | 可选开机自启 |

---

## 四、无 install 脚本时（纯手动拷贝）

若只把文件拷到 `~/pi_cloud_deploy/` 而没有运行 install：

```bash
cd ~/pi_cloud_deploy
sudo apt install -y python3-venv v4l-utils fonts-noto-cjk dos2unix ffmpeg
dos2unix *.sh
chmod +x *.sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-pi-client.txt
mkdir -p ~/elephant_clips
./run_pi_cloud_client.sh
```

## 五、默认参数（pi_cloud_config.sh）

| 变量 | 值 |
|------|-----|
| `CAMERA_WIDTH` / `HEIGHT` | 1920 × 1080 |
| `PI_CLIP_MAX_WIDTH` | 1920 |
| `PI_CLIP_RETENTION_DAYS` | 3 |
| `PI_CLIP_DELETE_AFTER_UPLOAD` | 1 |

## 七、排查

| 问题 | 处理 |
|------|------|
| `cannot execute` | `dos2unix *.sh && chmod +x *.sh` |
| 摄像头失败 | `python pi_cloud_client.py --probe-camera` |
| 上传失败 | 确认服务器已 scp 更新且 `/health` 正常 |
